# Smart Warehouse Inventory System

A complete Warehouse Inventory Management System that combines digital hardware design using Verilog HDL with business intelligence dashboards built in Power BI.

This project demonstrates how warehouse operations can be monitored at both the hardware and analytics levels by integrating inventory counting logic with interactive business dashboards.

📖 Project Overview

The Smart Warehouse Inventory System is designed to simulate warehouse inventory operations while providing real-time business insights through interactive dashboards.

The project consists of two major components:

- VLSI Design
  - Inventory monitoring logic designed using Verilog HDL
  - RTL simulation and verification
  - Timing analysis using Intel Quartus Prime

- Business Analytics
  - Interactive Power BI dashboard
  - Inventory analytics
  - Sales analytics
  - Demand forecasting
  - Product performance analysis

This project demonstrates both hardware design and data analytics, making it suitable for semiconductor, embedded systems, and data analytics portfolios.
